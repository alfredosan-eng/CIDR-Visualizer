¿Qué significa el número después de /?

El prefijo CIDR indica cuántos bits iniciales de una dirección pertenecen a la red. Esta página permite cambiar el prefijo y observar cómo se mueve la frontera entre la parte de red y la parte restante de la dirección.

1. La idea fundamental

En IPv4 una dirección tiene 32 bits. En IPv6 tiene 128 bits. Cuando escribimos /24, /26 o /64, ese número representa la cantidad de bits iniciales que forman el prefijo de red.

/n = n bits de prefijo

Por ejemplo, 192.168.1.0/24 significa que los primeros 24 bits pertenecen al prefijo de red y quedan 8 bits fuera de ese prefijo.

2. ¿Qué cambia al mover el /?

/2424 bits de red · 8 de host · 256 direcciones
/2525 bits de red · 7 de host · 128 direcciones
/2626 bits de red · 6 de host · 64 direcciones
/2727 bits de red · 5 de host · 32 direcciones

Cada bit que se agrega al prefijo se toma de la parte restante. En IPv4, cada aumento de un bit reduce a la mitad el tamaño del bloque.

3. El número después del / no es una máscara decimal

Es una longitud de prefijo. La máscara decimal es otra representación de la misma frontera.

/2411111111.11111111.11111111.00000000255.255.255.0
/2611111111.11111111.11111111.11000000255.255.255.192
/1911111111.11111111.11100000.00000000255.255.224.0
